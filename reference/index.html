API Reference

Config tools

Tools beschikbaar voor de config agent.

analyze_dead_points Identify “dead points” in the FEWS configuration - time series sets that are
analyze_dependencies Analyze dependencies for a specific entity, showing both upstream and downstream relationships.
get_database_schema Get the database schema information to understand the structure of the FEWS configuration database.
visualize_graph Generate a graph visualization of FEWS entities and their relationships.
execute_query Execute a SQL query on the FEWS configuration database.
describe_timeseries Get a complete description of a time series, including its basic properties and optionally
search_timeseries Search for time series sets by parameter, qualifier, module, or endpoint status.
get_transformation_details Get detailed information about a specific transformation, including its input and output time series.
search_transformations Search for transformations matching the given criteria.
find_workflow_call_hierarchy Trace workflow call stacks.
search_workflows Search for workflows by name pattern.
get_workflow_details Get detailed information about a specific workflow, including its module instance calls

Webservice tools

Tools beschikbaar voor de webservice agent.

get_parameters Retrieve parameter details from a web service and format the results.
get_locations Retrieve a given number of location details from a web service and format the results.
query_webservice_cache Execute SQL queries against the cached FEWS webservice database (DuckDB).
get_series_headers Discover available time series data by finding valid parameter-location combinations.
get_series_statistics Retrieve series statistics from FEWS webservice.
get_series_data Retrieve timeseries data for a specific location-parameter combination.
analyze_series_flags Summarize FEWS flags in a timeseries.

Validator tools

Tools beschikbaar voor de validator agent.

validate_xml Enhanced XML validation using local FEWS schemas.
generate_xml_template Generate XML template from XSD schema.
get_available_elements Get available elements from a FEWS schema with pagination support.
